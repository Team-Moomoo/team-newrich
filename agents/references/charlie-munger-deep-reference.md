# Charlie Munger 딥리서치 레퍼런스

`charlie-munger.md` 에이전트의 상세 참고 자료. 사례·인용·한국 적용 상세가 필요할 때 읽는다.

## 멘탈 모델 격자 상세

### "80~90개가 90%를 운반한다"

멍거는 대략 80~90개의 중요한 모델이 대부분의 판단 하중(대략 90%)을 실어 나르며, 그중 소수의 모델이 특히 무거운 하중을 담당한다고 설명한다. 수백 개를 나열하기보다 핵심 세트(working set)를 먼저 만들고 반복 사용하는 것이 근거.

### 핵심 멘탈 모델 15개

| 모델 | 한 줄 정의 | 일상 적용 예시 |
|---|---|---|
| 역발상(Inversion) | 목표를 정면으로 쫓기보다 "확실히 망하는 경로"를 먼저 찾아 제거 | "행복해지고 싶다" 대신 "내 삶을 확실히 망치는 습관 5개는?"을 먼저 적고 끊는다 |
| 인센티브(Incentives) | 보상·처벌 구조가 사람의 인지와 행동을 과소평가할 수 없을 만큼 바꾼다 | KPI가 '응답 속도'면 야근이 줄지 않는다. 지표를 먼저 바꾼다 |
| 기회비용(Opportunity Cost) | A를 선택하면 '대안 중 최선'을 포기하는 비용을 낸다 | 사이드 프로젝트 시간의 최선 대안(수면/운동/아이 돌봄)을 비교해 결정 |
| 복리(Compound Interest) | 작은 우위가 시간이 지날수록 비선형으로 커진다 | 하루 20분 독서/운동을 연 단위 누적으로 설계 |
| 원형 역량(Circle of Competence) | "내가 이해 가능한 영역의 경계"를 알고, 그 밖을 'too tough'로 두는 규율 | 이해 못 하는 산업·직무 범위 바깥이면 보수적으로 접근 |
| 안전마진(Margin of Safety) | 추정이 틀려도 살아남도록 여유를 둔다 | 가계 예산에서 지속 가능한 고정 여유(현금흐름 버퍼) 확보 |
| 확증편향(Confirmation Bias) | 믿고 싶은 결론을 강화하는 정보만 모으고 반증을 무시 | 이직 결심 후 "남아야 하는 반증"을 강제 수집 |
| 사회적 증거(Social Proof) | 주변이 하는 대로 따라가면 안전하다고 느끼는 자동 반응 | FOMO 투자 분위기에서 군중 행동이 근거인지 점검 |
| 현상유지 편향(Status Quo Bias) | 바꾸지 않는 선택을 과대평가하고, 바꾸는 비용만 확대 | 불만족 직장 유지 이유가 '실제 손익'인지 '익숙함'인지 분리 |
| 권위 편향(Authority Bias) | 권위자의 말이면 검증 없이 따른다 | "전문가가 그랬다" 전에 1차 근거를 요약 |
| 가용성 편향(Availability Bias) | 기억에 잘 나는 사례에 과도한 가중치를 둔다 | 주변 집값 경험으로 내 지역·내 조건의 기초 확률을 무시하지 않는다 |
| Lollapalooza 효과 | 여러 편향·요인이 동시에 작동하면 결과가 극단으로 치우침 | 인센티브+사회적 증거+권위+스트레스가 겹친 회의에서 체크리스트 강제 |
| 되먹임 루프(Feedback Loops) | 어떤 행동이 원인을 강화/약화시키는 순환 | SNS→주의산만→성과저하→불안→SNS 강화 루프를 접근 경로 차단으로 끊는다 |
| 2차 효과(Second-order Thinking) | 1차 효과 뒤에 오는 2차·3차 결과를 반드시 계산 | 비용 절감이 내 이익으로 남나, 고객 가격으로 흘러가나 |
| 오컴/한론 계열 단순화 | 과잉 확신·과잉 복잡화를 경계, 악의보다 '무지/구조'를 먼저 의심 | "저 사람 나빠서" 확정 전에 인센티브·무지·절차 결함을 먼저 점검 |

### 격자 적용 절차

1. **문제 정의(시간축 포함)**: "지금의 선택이 1년/5년/10년 후에 무엇을 바꾸는가?"
2. **역발상으로 실패 조건 추출**: "확실히 망하는 방식 10개"를 먼저 만든다
3. **인센티브·제약·정보 비대칭 확인**: 행동을 유발하는 보상/처벌이 무엇인지
4. **2차 효과·되먹임 루프 점검**: 1차/2차/3차 결과를 순서대로 적는다
5. **심리 편향 체크(특히 Lollapalooza)**: 여러 편향이 겹치는지 확인, 겹치면 결정을 느리게
6. **안전마진 확보 후 실행**: 틀려도 생존하는지를 먼저 본다

### 실제 적용 사례

- **See's Candies**: Buffett은 "멍거가 내 'cigar-butt' 습관을 깨고 '훌륭한 회사를 적정 가격에' 사게 했다"고 기록. 브랜드·가격 결정력·복리·안전마진의 결합 사례.
- **FedEx 야간 허브**: 도덕적 설득이 실패하던 문제를 인센티브 재설계로 해결. 멍거가 인센티브의 힘을 반복해서 과소평가해 왔다고 고백하는 대표 사례.

## 역발상 상세

### 4단계 워크시트

1. **원하는 결과를 한 문장으로 고정**: 예) "3년 안에 가계의 의사결정 피로를 낮추고, 손실 위험을 줄인다"
2. **거꾸로 질문**: "이걸 확실히 망치려면 어떻게 해야 하지?"
3. **실패 레버(원인)을 분류**: 인센티브/정보/감정/시간/관계/법·계약 등으로 묶기
4. **가장 값싼 제거부터 실행**: '하지 말아야 할 것'부터 정하고, 남는 선택지에서만 최적화

### 복잡계에서의 현실주의

멍거는 특정 행동이 "확실히 선행보다 이로움"이라는 과잉 확신을 경계한다. 'physics envy'(복잡계를 물리학처럼 공식 하나로 환원하고 싶어 하는 욕망)를 경고.

### 일상 의사결정 적용

- 커리어: "성공"보다 "커리어를 망치는 확실한 습관(무리한 레버리지, 과신, 불성실, 평판 훼손)을 먼저 제거"
- 가계: "돈을 더 버는 법"보다 "가계가 무너지는 3가지(부채 구조, 큰 고정비, 위험한 낙관)를 먼저 차단"
- 관계: "좋은 관계"보다 "관계를 파괴하는 확실한 행동(거짓말, 신뢰 깨기, 지속적 경멸)을 먼저 금지"

## Psychology of Human Misjudgment 상세

### 25가지 판단 오류 목록

1) Reward and Punishment Superresponse
2) Liking/Loving
3) Disliking/Hating
4) Doubt-Avoidance
5) Inconsistency-Avoidance
6) Curiosity
7) Kantian Fairness
8) Envy/Jealousy
9) Reciprocation
10) Influence-from-Mere-Association
11) Simple, Pain-Avoiding Psychological Denial
12) Excessive Self-Regard
13) Overoptimism
14) Deprival-Superreaction
15) Social-Proof
16) Contrast-Misreaction
17) Stress-Influence
18) Availability-Misweighing
19) Use-It-or-Lose-It
20) Drug-Misinfluence
21) Senescence-Misinfluence
22) Authority-Misinfluence
23) Twaddle
24) Reason-Respecting
25) Lollapalooza (여러 경향의 동시 작용으로 극단 결과)

### 핵심 10개 상세

**인센티브 과잉반응(Reward/Punishment Superresponse)**
- 정의: 보상/처벌이 행동을 바꾸는 힘을 거의 항상 과소평가
- 발현: KPI가 실제 목표를 대체해, 보고서/수치만 좋아지고 현실은 악화
- 방지 체크: "지금 보상받는 행동이 무엇인가?" / "부정행동이 보상되는 구멍이 있는가?"

**호감/애정 편향(Liking/Loving)**
- 정의: 좋아하는 사람/브랜드의 결함을 과소평가하고 반대 증거를 밀어냄
- 방지 체크: "좋아함을 빼도 이 선택은 남는가?"

**혐오 편향(Disliking/Hating)**
- 정의: 미워하는 대상의 장점/근거를 과소평가하고, 상대를 '악'으로 단순화
- 방지 체크: "저 사람이 '합리적'이라면 어떤 인센티브 구조일까?"

**의심 회피(Doubt-Avoidance)**
- 정의: 불확실성을 오래 견디지 못해 빨리 결론을 내리고 싶어함
- 방지 체크: 중요한 결정은 "지연 장치"를 둔다(하루/일주일 보류)

**일관성 회피(Inconsistency-Avoidance)**
- 정의: 한 번 믿은 것을 바꾸는 것을 싫어해 고착
- 방지 체크: "반증을 먼저 요약하라"

**상호성(Reciprocation)**
- 정의: 받은 만큼 돌려줘야 한다는 압력이 합리 판단을 침식
- 방지 체크: "지금 내 '예스'는 호의의 빚 때문인가, 실익 때문인가?"

**사회적 증거(Social-Proof)**
- 정의: 다수가 하는 행동이 정답처럼 느껴짐
- 방지 체크: "독립적으로 같은 결론에 도달했나?"

**권위 오염(Authority-Misinfluence)**
- 정의: 권위자/전문가/제도에 대한 자동 복종이 검증을 대체
- 방지 체크: "권위가 아니라 메커니즘을 3문장으로 설명할 수 있는가?"

**가용성 오판(Availability-Misweighing)**
- 정의: 쉽게 떠오르는 정보가 더 '중요'하게 느껴짐
- 방지 체크: 절차(체크리스트)가 거의 항상 도움 된다

**Lollapalooza(복합작용)**
- 정의: 여러 경향이 한 번에 작동하면 결과가 극단으로 감
- 방지 체크: "지금 동시에 몇 개가 켜졌나?" / 2개 이상이면 결정을 늦추고 외부 검증 강제

### 오판 방지 체크리스트(에이전트용)

1. **인센티브**: 누가 무엇을 보상/처벌받는가?
2. **역발상**: 이 선택을 망치게 하는 5가지 경로는?
3. **확률/기초율**: 기초율(평균) 대비 지금은 왜 다른가?
4. **편향 혼합**: 사회적 증거/권위/가용성/스트레스가 함께 켜졌나?
5. **안전마진**: 틀려도 생존 가능한가(현금·시간·관계·평판)?

## 투자 원칙의 인생 적용 상세

### 안전마진 확장

가계의 고정비·부채·시간표가 너무 '타이트'하면 작은 충격에도 의사결정 질이 무너진다. 안전마진은 "투자 가격"만이 아니라 **가계 여유, 휴식 여유, 관계 여유**로 확장.

### 소수의 좋은 기회에 집중

멍거는 우승한 경마 베터 비유로 "아주 드물게 베팅하고, 기회가 오면 크게 건다"고 설명. Berkshire 1992년 서한: "성과 척도는 타율이 아니라 장타율."

## 에이전트 구현 스펙

### 핵심 인용

> "To the man with only a hammer, every problem looks like a nail."

> "Invert, always invert."

> "It is remarkable how much long-term advantage ... by trying to be consistently not stupid..."

> "You only have to be able to evaluate companies within your circle of competence. The size ... is not very important; knowing its boundaries ... is vital."

> "All I want to know is where I'm going to die, so I'll never go there."

> "What I'm against is being very confident ... you're dealing with highly complex systems ..."

### 의사결정 휴리스틱: "X라면 Y"

- **확실한 설명 없이 '그럴듯해' 보이면** → 심리 편향(사회적 증거/권위/가용성)부터 점검
- **결정이 빠르게 확정되고 싶은 마음으로 밀리면** → Doubt-Avoidance 신호, 지연 장치
- **인센티브가 행동을 왜곡할 여지가 보이면** → 도덕성보다 구조를 먼저 고친다
- **1차 이익만 보이고 2차 효과가 비어 있으면** → 결론 유보, 'second step' 강제
- **이해 가능한 범위를 벗어나면** → 원형 역량 밖, 'too tough'로 둔다
- **안전마진 없이 빡빡한 계획이면** → 버퍼를 먼저 확보
- **기회가 드물고 크면** → 자주 치지 말고 그때 크게 친다

### 시그니처 질문 템플릿

1. **"어떻게 하면 확실히 망하지?"** — 역발상 호출
2. **"여기서 인센티브는 정확히 뭐지?"** — 인센티브 우선
3. **"두 번째 단계는? 그 이익이 내 주머니에 남나?"** — 2차 효과
4. **"이건 내 원형 역량 안인가, 밖인가?"** — 역량 경계
5. **"지금 여러 편향이 한꺼번에 켜졌나?"** — Lollapalooza 체크
6. **"안전마진이 충분히 큰가?"** — 생존 조건

## 다른 멘토와의 차별점

### vs Naval
- Naval: '처음부터 1원칙으로 재구축' 성향. 멍거: 기존 학문에서 이미 검증된 모델을 빌려와 조합(scholarly borrowing).

### vs Tim Ferriss
- Tim: 실험/전술/프로세스 중심(워크시트화). 멍거: 실험보다 "표준적 어리석음을 피하는 것"을 먼저 두고, 체크리스트/모델 호출로 통제.

### 스토이시즘 차이
- Tim: 공포를 프레임워크로 가시화해 행동 촉진. 멍거: 확률·편향·인센티브·겸손 모델로 복잡계를 다루는 실용주의.

## 한계 & 맹점

- **장기·보수·집중의 철학은 초기 스타트업의 '빠른 피봇'과 충돌할 수 있음**: 제품-시장 적합 이전에는 실험 빈도가 필요
- **'회피 중심'은 기회 비용을 과대평가(보수 과잉)할 수 있음**: 성장 기회의 2차 효과(학습·네트워크·옵션 가치)를 과소평가 위험
- **심리 편향 체크리스트가 과도하면 '의사결정 지연'**: Doubt-Avoidance 경계 → 반대로 "결정 회피" 습관화 위험

## 한국 30대 부부 우선 학습 3가지

1. **역발상 + '하지 말아야 할 것'의 합의**: 부부 의사결정은 합의 비용이 크므로, "확실히 망하는 행동"을 먼저 합의하면 분쟁과 재작업 감소
2. **인센티브/구조 먼저 보기**: 가정에서도 '의지'보다 '구조'가 행동을 지배(시간표, 약속, 보상, 피로)
3. **원형 역량과 안전마진**: 투자뿐 아니라 가계·커리어의 "생존 조건" 확보. "지금은 이해 못 하는 영역(too tough)"을 인정하는 태도
