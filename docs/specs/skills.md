# team-newrich Skills

멘토 자문 플러그인의 스킬 정의.

## 공통 규칙

- 모든 스킬은 프로젝트 루트에서 `our-situation.md`를 탐색한다. 있으면 읽고 반영, 없으면 컨텍스트 없이 진행
- 멘토 에이전트에 한국 맥락 보정이 내장되어 있으므로 스킬에서 별도 지시 불필요
- 존재하지 않는 멘토명 입력 시 에러 메시지 + 사용 가능 멘토 목록 출력

## /ask — 멘토 1명에게 질문

### 용도

특정 멘토의 관점에서 인사이트를 얻는다.

### Input

```
/ask {멘토명} {질문}
```

- 멘토명: tim, naval, kepano, charlie (약칭 허용)
- 질문: 자유 텍스트

### 동작

1. 프로젝트 루트에서 `our-situation.md` 탐색 (있으면 읽고 반영, 없으면 컨텍스트 없이 진행)
2. 지정 멘토 에이전트 호출
3. 해당 멘토의 프레임워크를 적용하여 답변

### Output

멘토 관점의 답변. 프레임워크 적용 시 어떤 프레임워크를 사용했는지 명시.

## /debate — 멘토 2명 토론

### 용도

두 멘토의 서로 다른 관점을 비교하여 다각적 인사이트를 얻는다.

### Input

```
/debate {멘토A} {멘토B} "{주제}" [라운드수]
```

- 멘토A, 멘토B: 서로 다른 멘토 2명
- 주제: 토론 주제
- 라운드수: 선택. 기본값 1. 각 라운드 = A 의견 → B 반론 → B 의견 → A 반론

### 동작

1. 프로젝트 루트에서 `our-situation.md` 탐색 (있으면 읽고 반영, 없으면 컨텍스트 없이 진행)
2. 라운드 반복:
   - 멘토A 에이전트: 주제에 대한 자기 관점 제시 (첫 라운드) 또는 상대 반론에 대한 재반론
   - 멘토B 에이전트: A 의견에 대한 반론 + 자기 관점 제시
   - 멘토A 에이전트: B 의견에 대한 반론
3. 지정 라운드 완료 후 종합 정리: 공통점, 차이점, 실행 가능한 결론

### Output

라운드별 토론 내용 + 종합 결론. 지정 라운드 안에 결론까지 도출.

### 규칙

- 같은 멘토 2명 지정 시 에러
- 라운드수는 1~5 범위. 초과 시 5로 제한

## /council — 멘토 라운드테이블

### 용도

여러 멘토의 관점을 모아 종합적 인사이트를 얻는다.

### Input

```
/council "{주제}" [멘토1 멘토2 ...]
```

- 주제: 라운드테이블 주제
- 멘토 목록: 선택. 생략 시 전체 멘토 참여. 2명 이상 지정 필수 (1명이면 /ask 사용 안내)

### 동작

1. 프로젝트 루트에서 `our-situation.md` 탐색 (있으면 읽고 반영, 없으면 컨텍스트 없이 진행)
2. 참여 멘토 각각 순차 호출: 주제에 대한 자기 관점 제시
3. 종합 정리: 각 멘토 핵심 포인트 요약 + 공통 방향 + 상충 지점 + 실행 제안

### Output

멘토별 의견 + 종합 정리.
